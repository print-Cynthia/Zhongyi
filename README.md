# 草本知行（Herb Journey）

> 身体在说话，本草在回答。

这是一个用「身体信号」去对话中医药的小工具。胃胀、失眠、上火、怕冷、咳嗽——这些日常感受背后，对应着不同的中医方向。打开应用，顺着几轮问答走一遍，你会得到一份可参考的方向清单，配上一组按相关性加权的本草推荐，作为日常调理思路的入门。

---

## 你能用它做什么

### 中药百宝柜（首页）

走进应用的第一眼，是一座立体的中药百宝柜。16 味最常用的核心药材，以 4×4 的抽屉网格陈列。点击任意抽屉便"拉开"，看到它的性味归经、功效方向与一段通俗解读——像打开自己家的药柜一样直观。

### 本草查询

应用内置 **78 味常用中药**，覆盖补气 · 补血 · 补阳 · 养阴 · 补肾 · 温里 · 理气 · 活血 · 清热 · 化湿 · 利水 · 解表 · 止咳 · 安神 · 消食 · 健脾等品类。

每一味药材都按同一套结构呈现：

- **性味与归经**（例如：甘、微温，归肺、脾经）
- **功效方向**（它能帮你理解哪类身体信号）
- **经典配伍思路**（与哪些药材搭配、方向如何）
- **使用注意与禁忌提示**
- **一段通俗解读**，把专业术语翻译成日常语言

### 身体信号整理

不需要懂中医术语。顺着几轮问答，描述你最近的状态（"最近容易累、胃口不好、便稀"之类），系统会把你给的信号归纳成一份中医调理方向：

- **一级 · 方向结论**：把零散信号收敛到一个明确的中医调理思路。
- **二级 · 本草推荐**：在一级结论之外，按相关度独立给出一组本草，标注匹配度，让你看见「为什么推荐它」。

两者互不替代——一级定方向，二级给抓手。

## 适合你吗

- 对中医药感兴趣，但被知识体系劝退过的初学者；
- 日常小毛病想找方向，又不至于上升到就医程度的普通用户；
- 想用一杯茶的时间，看看中医是如何看待这类信号的探索者。

---

## 视觉与节奏

米色与青色为主的克制配色；首页 3D 立体药柜，抽屉可"拉开"；本草卡片化排版，悬停有反馈。整段体验没有弹窗、没有营销，节奏跟着你的步调走。

---

## 重要提醒

本草应用旨在提供日常参考与方向梳理，**不是医疗诊断或处方建议**。

- 任何急症、孕期、慢性病或严重不适，请咨询执业中医师或药师后再做决策；
- 标注「孕妇忌用」「生品有毒」「脾胃虚寒慎用」等提示的药材，严禁自行使用；
- 中药材存在配伍禁忌与剂量差异，应用内容不替代专业医师面诊。
