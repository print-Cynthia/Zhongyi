# 草本知行（Herb Journey）

> 草本智慧，触手可及 —— 查询中药知识，整理身体表现，轻松理解中医调理思路。

草本知行是一个面向中医药知识学习与「身体信号整理」的轻量级网页应用。它用可视化、可交互的方式，帮助你在日常中建立对常用中药材、经典方剂与身体表现之间关系的初步认知。

> 重要声明：本应用内容仅供中医知识学习与个人健康认知参考，**不构成任何医疗诊断、处方或治疗建议**。如有健康问题，请务必咨询执业中医师或正规医疗机构。

---

## 你能用它做什么

### 1. 中药百宝柜（首页）

打开首页就是一座立体的中药百宝柜。柜中精选了 **16 味最常用的核心药材**，以 4×4 的抽屉网格陈列。点击任意抽屉即可「拉开」，查看这味药材的性味归经、功效方向与通俗解读——像打开自家的药柜一样直观。

### 2. 草本查询

在查询页，你可以按**药名**、**功效**或**身体表现**进行检索。每一味药材都会以结构化的方式呈现：

- **性味与归经**（如「甘、微温，归肺、脾经」）
- **功效方向**（它能帮你理解哪些身体信号）
- **经典配伍思路**（与哪些药材搭配、方向如何）
- **使用注意与禁忌提示**
- **一段通俗解读**，把专业术语翻译成日常语言

### 3. 身体信号整理

这是应用最有特色的部分。你不需要懂中医术语——只要顺着多步问答，描述自己的身体状况（例如「最近容易累、胃口不好、大便偏稀」），系统就会把这些信号整理归纳，映射到相应的中医调理方向，并给出参考性的经典方剂与本草推荐，帮你建立初步的认知框架。

## 药材知识库

应用内置 **78 味核心高频药材**，覆盖以下品类：

**补气 · 补血 · 补阳 · 养阴 · 补肾 · 温里 · 理气 · 活血 · 清热 · 化湿 · 利水 · 解表 · 止咳 · 安神 · 消食 · 健脾**

每一味药材都经过规范化整理，包含性味归经、功效方向、配伍思路、禁忌提示与通俗解读，可与「身体信号整理」和「草本查询」两大模块无缝联动。

---

## 智能检索：两级级联

为了既给出「方向性结论」又提供「可解释的本草建议」，应用采用两级级联检索：

- **一级 · 5D 方剂矩阵**：把你描述的身体信号收敛到明确的中医调理方向，并给出参考性的经典方剂结论。
- **二级 · 本草特征索引**：在一级结论之外，按相关性加权，独立给出一组本草推荐，并标注匹配度，让你清楚「为什么推荐这味药」。

两级互相补充、互不替代：前者定方向，后者给抓手。

## 如何开始使用

本项目是纯静态网页，无需安装任何依赖。

**方式一：直接打开**

双击 `index.html`，即可在浏览器中运行。

**方式二：本地静态服务器（推荐，体验更一致）**

```bash
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 部署到 GitHub Pages

如果你想把这个站点发布到网上，可以通过 GitHub Pages 免费托管：

1. 把本仓库推送到 GitHub。
2. 在仓库 **Settings → Pages** 中，将 **Source** 设为 `Deploy from a branch`，分支选择你的默认分支，目录选择 `/ (root)`。
3. 保存后等待几分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
