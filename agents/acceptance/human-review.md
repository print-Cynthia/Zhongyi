# 验收 · 用户人工终审签字项

> 稳定层。你在审批闸上的终审清单。agent 团队（主管 + PM）起草边界文件后，你在此签字放行或打回。

## 你在终审看什么（无需写代码，只看边界对不对）
1. **范围越界**：有没有哪个员工越权做了诊断 / 开方 / 长周期档案？→ 应只在"整理 / 参考 / 学习"边界内。
2. **风格跑偏**：设计组 / 前端有没有引入新色、改字体、动药柜透视、漏掉版本号 +1？→ 应 verbatim 照 [style-guide.md](../../style-guide.md)。
3. **医学准确性**：中医组的辨证 / 本草 / 古籍依据是否靠谱、有无禁忌标注、毒性是否强预警？→ 红线级。
4. **合规红线**：免责声明是否在、急症红牌文本是否命中、有无诊断 / 处方 / 疗效承诺词？→ 红线级。
5. **体验指标**：4 步流程是否顺畅、文案是否通俗亲切、完成率 / 召回率是否可达成？
6. **迁移可用性**：`staff/` 与 `domain/` 是否清晰可换、README 三步迁移是否照做？

## 终审操作
- **放行**：全部达标 → 签字，进入下一轮（模块代码实现：替换硬编码 renderReport、接 5 Skill、照 Style Bible 渲染）。
- **打回**：任一项不达标 → 批注具体哪个员工 / 哪个文件，打回对应部门修订，回到自动预检。

## 本轮（工作台骨架）终审重点
- 看 `agents/` 整套是否：① 架构与 v4 / v5 一致；② 每个员工边界文件齐全（18 个）；③ 设计铁律落实；④ PRD 5 Skill 映射无遗漏；⑤ README 可读、迁移三步清晰。
- 网站代码（index.html / script.js / style.css / data.js）本轮**不动**，无需你审代码。
