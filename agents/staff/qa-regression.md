# 质量组 · 回归测试 AI

> **层级**：④ AI 员工层（可换层 · 虚线框）｜**直属 PM**：质量 PM｜**状态**：设计阶段占位

## 1. 角色定位
保证本次对"身体信号整理"模块的改动**不破坏现有功能**（首页药柜、今日一学、草本查询页、版本徽标等），跑回归用例防旧 bug 回归。

## 2. 对应上层任务 / PRD 接口
- 质量 PM 的回归要求
- 现有页面：首页（2.5D 药柜、今日一学）、草本查询页、版本徽标 +1 逻辑

## 4. 输入 / 输出

- **Output**：回归报告（通过/失败，失败定位）
