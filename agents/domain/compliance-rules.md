# 领域层 · 合规规则（Compliance Rules）

> 领域层。本文件定义免责声明固定文本、急症红牌清单、红线词与隐私脱敏规则。供合规组员工与工程组 Safety Shield / ReportFormatter 引用。

## 1. 固定免责声明（必须出现于每个用户可见产出）
- 报告底栏 / 每页：`提示：本报告仅用于身体表现整理和中医知识学习，不构成医疗诊断或处方建议。`
- 纯文本复制载荷末尾追加：`（提示：本报告仅用于身体表现整理与中医知识学习，不构成医疗诊断或处方建议。）`

## 2. 急症红牌（Safety Shield 硬性切断）
- **前置扫描**：Skill 1 执行前，系统注入静态危急重症敏感词库。
- **触发条件**（命中其一即切断）：急性心脑血管、大出血、严重外伤或急性中毒等高风险词，含：
  - 胸痛剧烈
  - 吐血
  - 呼吸困难
  - 剧烈头痛伴呕吐
  - 昏迷
- **拦截响应**：立即终止当前 Agent 调度，不进入 Skill 1-5。
- **固定合规文本**（红色警告卡片）：
  > ⚠ 安全提示：检测到您描述的症状可能属于急性或重症健康风险。本系统仅作轻量级健康整理，无法提供急救或临床诊断。请立即拨打 **急救电话或前往最近的医院急诊科就医！**

## 3. 红线词（严禁出现，合规边界 AI 拦截）
- 诊断类：确诊、你得了 XX 病、病名诊断结论
- 处方类：开药、药方、剂量、抓药、遵医嘱服用 XX
- 疗效承诺：治愈、保证有效、百分百、包好
- 替代就医：不用去医院、比医生准、替代医师
- 任何暗示"本系统可做医疗诊断或处方"的表述

## 4. 隐私保护（脱敏 / 不留存）
- 用户输入仅在本次会话内用于生成报告，不得长期留存敏感信息。
- 前端通过 `sessionStorage` 持久化当前轮次状态与已确认标签（仅用于"恢复上次进度"），不写入服务端日志。
- 报告中不回显可识别个人身份的信息（姓名、电话、地址）。
- 导出 / 复制文本不含超出用户主动输入之外的个人数据。

## 5. 与中医组协同边界
- 医学表述（辨证方向、本草推荐）不得越过"整理 / 参考 / 学习"边界，落到诊断 / 处方即红线。
- 毒性药材无论是否匹配，须无条件强预警（见 tcm-prd-skills.md Skill 4）。
