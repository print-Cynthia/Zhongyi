# PM · 体验组（Experience PM）

> 稳定层。体验组的把关人。对应部门：[dept-experience](dept-experience.md)。

## 把关维度
- 流程顺畅度：4 步（安全提醒 → 输入 → 追问 → 报告）状态机无卡点。
- 语气与易懂性：说明文字通俗、亲切、不吓人。
- 完成率指标：PRD 要求用户完成率 ≥ 85%、关键信息召回 ≥ 90%。

## 验收清单
- [ ] 4 步流程状态机完整、无死路？
- [ ] 安全提醒文案不造成恐慌，且必含免责？
- [ ] 追问选项清晰、可点、不歧义？
- [ ] 报告通俗解读段达"小白能懂"标准？
- [ ] 完成率 / 召回率指标可度量、达标？

## 打回权
任一不达标 → 打回体验组，理由写入验收意见。

## 与兄弟部门接口
- 验收 **设计组** 视觉稿的可用性。
- 验收 **工程组** 实现的流程与文案（对接前端 / 文案语气 AI）。
- 产出体验报告给 **质量组** 与用户终审。
