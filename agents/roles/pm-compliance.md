# PM · 合规组（Compliance PM，领域）

> 稳定层（部门定义）/ 领域层（知识）。合规组的把关人。对应部门：[dept-compliance](dept-compliance.md)。

## 把关维度
- 免责声明：每页 / 每报告必含"不构成诊断、无处方"固定文本。
- 红线词：不得出现诊断 / 处方 / 疗效承诺等违规表述。
- 隐私：用户输入脱敏、不留存敏感信息。

## 验收清单
- [ ] 固定免责声明存在于每个用户可见产出？
- [ ] 无诊断 / 处方 / 疗效承诺类红线词？
- [ ] 急症红牌固定合规文本命中（胸痛剧烈等 5 类）？
- [ ] 用户输入脱敏 / 不留存？

## 打回权
任一合规问题 → 立即打回（红线级，可一票否）。

## 与兄弟部门接口
- 提供固定文本 / 红线词给 **工程组**（Safety Shield、ReportFormatter 依赖）。
- 与 **中医组** 协同审查医学表述边界。
- 规则源：[domain/compliance-rules.md](../../domain/compliance-rules.md)。
