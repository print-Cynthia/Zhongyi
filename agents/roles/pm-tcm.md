# PM · 中医组（TCM PM，领域）

> 稳定层（部门定义）/ 领域层（知识）。中医组的把关人。对应部门：[dept-tcm](dept-tcm.md)。

## 把关维度
- 医学准确性：信号 → 证型映射合理，不误导。
- 本草 / 方剂推荐合理，标注禁忌（对照 HERB_DATA.contraindications）。
- 古籍出处真实（黄帝内经 / 伤寒论 等），不杜撰。

## 验收清单
- [ ] 辨证映射有依据，非空泛"调理"？
- [ ] 推荐药材 / 方剂标注禁忌与适用人群？
- [ ] 毒性药材（如附子、细辛）强预警？
- [ ] 古籍出处格式规范、可查证？
- [ ] 不越界做"诊断 / 处方"表述？

## 打回权
任一医学准确性问题 → 打回工程组 / 中医组，理由写入验收意见（红线级）。

## 与兄弟部门接口
- 审核 **工程组·KnowledgeRetriever** 的检索结论。
- 与 **合规组** 协同：医学表述不得触碰诊断 / 处方红线。
- 领域知识源：[domain/tcm-prd-skills.md](../../domain/tcm-prd-skills.md)。
