# PM · 设计组（Design PM）

> 稳定层。设计组的把关人。对应部门：[dept-design](dept-design.md)。

## 把关维度
- 视觉一致性：所有产出必须符合 [style-guide.md](../../style-guide.md)（:root 变量、字体、药柜透视、版本徽标）。
- 轻中式 / 现代简洁 语言不被稀释（留白、克制、木色 + 苔绿）。
- 组件复用率：新 UI 优先复用既有类（.navbar / .search-container / 卡片），不重复造。
- 响应式：6 个断点（1280 / 1101 / 1100 / 1024 / 900 / 768 / 480）不被破坏。

## 验收清单（打回依据）
- [ ] 颜色 100% 取自 :root 11 变量 + 药柜木色，无新 hex？
- [ ] 字体栈未改（Inter / PingFang SC / Microsoft YaHei / sans-serif）？
- [ ] 药柜透视参数未动（rotateY(-14deg) rotateX(1.5deg) / perspective 1200 / origin 30% 50% / 侧板 clip-path）？
- [ ] 版本徽标机制未破坏（fixed 右下、改动 +1）？
- [ ] 新组件是否复用既有类？复用率达标？
- [ ] 响应式断点全通过？

## 打回权
任一清单项不达标 → 打回设计组重做，理由写入验收意见，回到质量预检前。

## 与兄弟部门接口
- 输出视觉规范给 **工程组·前端开发AI**（实现时必须 verbatim 照做）。
- 与 **体验组** 协同：视觉稿需满足可用性 / 易懂性要求。
- 接受 **质量组** 自动预检（风格一致性项）。
