# PM · 质量组（Quality PM）

> 稳定层。质量组的把关人。对应部门：[dept-quality](dept-quality.md)。

## 把关维度
- 自动预检覆盖率：对照 [acceptance/auto-checklist.md](../../acceptance/auto-checklist.md)。
- 回归：本次改动不引入旧 bug。
- 边界 / 异常：极端输入、急症、JSON 失败、库缺数据的兜底。

## 验收清单（即自动预检项）
- [ ] JSON Schema 合规率 ≥ 99%？
- [ ] 解析报错有降级兜底？
- [ ] 风格一致性（对照 style-guide）？
- [ ] 免责声明必存在？
- [ ] 红牌文本必命中（急症路径）？
- [ ] 版本号 +1？

## 打回权
预检不通过 → 打回对应部门，质量 PM 拥有"预检一票否"权。

## 与兄弟部门接口
- 对所有部门产出跑预检。
- 预检报告交 **用户人工终审**。
- 依赖 **合规组** 红线词清单判定合规项。
