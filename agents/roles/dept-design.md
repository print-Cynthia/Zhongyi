# 部门 · 设计组（Design）

> 稳定层。对应 PM：[pm-design](pm-design.md)。下属 AI 员工：[staff/design](../../staff/design)。

## 部门职责
- 落地 [style-guide.md](../../style-guide.md) 视觉规范。
- 维护可复用组件库（按钮 / 卡片 / 表单 / 气泡 / Stepper / 骨架屏）。
- 定义页面流程与线框（交互原型）。

## 产出物
- 视觉规范落地说明（引用 style-guide 行号）。
- 组件库清单（含既有类复用说明）。
- 交互原型 / 线框（4 步流程状态机可视化）。

## 下属 AI 员工
- UI 视觉 AI（[ui-visual](../../staff/design/ui-visual.md)）：配色 / 排版 / 间距一致性。
- 组件库 AI（[components](../../staff/design/components.md)）：可复用组件维护。
- 交互原型 AI（[prototype](../../staff/design/prototype.md)）：流程 / 线框 / 状态机。

## 协作接口
- → 工程组·前端开发AI：交付视觉规范与组件，必须 verbatim 实现。
- ↔ 体验组：视觉稿需满足可用性 / 易懂性。
- → 质量组：接受风格一致性预检。
